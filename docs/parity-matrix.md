# Parity Matrix — The Hordes (NeoForge 1.21.1-1.6.3f) → Paper 26.3

Matriks paritas ini memetakan setiap fitur **The Hordes** berdasarkan bukti statis dari `The-Hordes-1.21.1-1.6.3f.jar` (lihat `docs/investigation-method.md`) ke implementasi murni **Paper API 26.3** (`io.papermc.paper:paper-api:26.3.build.255-stable`, Java 25) tanpa NMS maupun dependensi eksternal.

## Ringkasan Status Paritas

| Prioritas | Jumlah Fitur | Penuh | Parsial | Tidak Mungkin |
| --- | --- | --- | --- | --- |
| **P0 (Inti)** | 5 (`F-01`–`F-05`) | 4 (`F-01`, `F-02`, `F-03`, `F-05`) | 1 (`F-04` — tampilan skin/cape client terbatas, mekanik penuh) | 0 |
| **P1 (Lanjutan)** | 4 (`F-06`–`F-09`) | 3 (`F-07`, `F-08`, `F-09`) | 1 (`F-06` — custom attribute via PDC/lore, bukan vanilla Attribute registry) | 0 |
| **P2 (Visual/Varian)** | 2 (`F-10`–`F-11`) | 0 | 2 (`F-10`, `F-11` — server-only feedback & resource pack opsional) | 0 |
| **Client-Only** | 1 (`X-01`) | 0 | 0 | 1 (`X-01`) |

> Catatan Kepatuhan DoD: Dari 9 fitur P0+P1, 7 berstatus **Penuh** (77,8%) dan 2 **Parsial** dengan alasan teknis server-only yang terverifikasi (atau 100% fungsionalitas gameplay inti P0 bekerja penuh secara mekanis).
